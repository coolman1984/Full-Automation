# بصمة شغل — الأتمتة الكاملة

منصة محلية تربط وكيلك بمتصفح كروم وبرامج ويندوز، وتتيح له قراءة الشاشة وتنفيذ الخطوات ومراجعة النتيجة، ثم حفظ المهمة وإعادة تشغيلها ببيانات جديدة أو في مواعيد محددة.

النسخة الحالية تجريبية بإصدار ٠٫٣. فيها مسجل العمل الأول ومحرك الأتمتة وأدوات الوكلاء. التحكم في المتصفح اختُبر عمليًا، وتشغيل جسر ويندوز والجدولة لهما خطوات تحقق مستقلة.

ابدأ من [الخريطة الكاملة للقدرات والملفات](docs/PROJECT_MAP_AR.md)، أو افتح [فهرس التوثيق والمهارات](docs/README.md).

## ابدأ من هنا

١. نزّل المستودع وفكّه على ويندوز ١١. يلزم بايثون بإصدار ٣٫١٠ أو أحدث، وكروم، وأداة الوكيل التي تستخدمها بالفعل. لا توجد حزم بايثون إضافية مطلوبة للتشغيل.

٢. شغّل ملف الإعداد؛ يفحص الجهاز، ويبني ملفات ويندوز من المصدر، وينشئ إعدادات الربط:

```text
Setup.cmd
```

٣. لربط كلود المثبّت عندك، شغّل:

```text
Connect-Claude.cmd
```

ولربط كودكس بنفس الطريقة: `Connect-Codex.cmd`.

٤. افتح كلود بالنموذج الذي طلبته:

```powershell
claude --model claude-opus-5-5
```

٥. أعطه [تعليمات التشغيل](docs/AGENT_HANDOFF.md)، ثم وصف المهمة ونتيجتها المطلوبة. أدوات المنصة تظهر له باسم الخادم التالي:

```text
full-automation
```

الاشتراك وتوافر النموذج وتسجيل الدخول مسؤولية أداة الوكيل نفسها. المشروع لا ينشئ حسابًا ولا يضيف مفاتيح مدفوعة ولا يبدّل النموذج تلقائيًا. وإذا منعت سياسة جهازك التشغيل، لا تتغير هذه السياسة من خلال المشروع.

## الموجود في المشروع

| الجزء | الوظيفة |
|---|---|
| المتصفح | تبويبات، تنقل، قراءة عناصر الصفحة، كتابة، ضغط، مفاتيح، اختيار، تمرير، صور، رفع ملفات، مسار تنزيلات، وأوامر البروتوكول المباشرة |
| سطح المكتب | نوافذ وعناصر ونصوص متاحة للنظام، صور، تحديد نافذة، كتابة، مفاتيح، ضغط وسحب وتمرير |
| الوكلاء | تشغيل جلسات أوامر وقراءة الردود والأحداث؛ أربع تهيئات جاهزة وتهيئة لأداة إضافية |
| التسجيل البشري | تسجيل ظاهر للبرامج المختارة، وحفظ مشفّر، وتحويل المسجل إلى مهمة فيها نقاط المراجعة بوضوح |
| تسجيل الوكيل | حفظ استدعاءات الأدوات الناجحة، وتحويل قيم الإدخال إلى متغيرات افتراضيًا |
| المهام | متغيرات وشروط وتكرار وتحقق وانتظار، وتصدير كود، وتشغيل مباشر أو في الخلفية |
| المراجعة والاسترجاع | فحص الوصفة قبل التنفيذ، إلغاء محاولة في الخلفية، وسجل دائم بالخطوة وحالتها |
| إثبات الناتج | انتظار ملف أحدث ومستقر، وفحص حجمه ووقت تعديله وبصمته |
| المواعيد | يومي وأسبوعي ولمرة واحدة، باستخدام مجدول ويندوز وحساب المستخدم العادي |
| التشغيل المنضبط | قفل لمنع تعارض المهام، وسجل نتائج، وتوقف عام، ورفض إعادة محاولة الكتابة تلقائيًا دون تحديد أنها قابلة للتكرار |

تهيئات الوكلاء الجاهزة:

```text
Claude Code CLI · Codex CLI · Cline CLI · Antigravity agy CLI
```

## حدود لازم تكون واضحة

- لا توجد قدرة مضمونة تساوي الإنسان في كل البرامج. صفحات وعناصر غير قياسية، شاشات مؤمنة، صلاحيات مختلفة، واختبارات التحقق قد تحتاج تدخلك.
- قراءة شات أداة تعمل خارج المنصة تعتمد على ملف محادثة تحدده أو نص تكشفه نافذتها للنظام. لا توجد هنا قدرة مضمونة لاستعادة تاريخ مخفي لأي نافذة طرفية.
- الجلسات التي تبدأها المنصة تلتقط مخرجات الأمر أثناء العمل. وهي جلسات غير تفاعلية؛ الأسئلة التي تحتاج إدخالًا حيًا لا يجيب عنها البرنامج سرًا.
- أدوات الضغط عالية المستوى في المتصفح تعمل في الإطار الرئيسي والجذور المفتوحة. قراءة إطار محدد مدعومة؛ التحكم المتقدم بالإطارات المعزولة متاح من خلال أوامر البروتوكول المباشرة ويحتاج تحديد الجلسة الصحيح.
- التحكم بسطح المكتب يحتاج جلسة ويندوز مفتوحة وغير مقفلة. الجدولة لا تتجاوز القفل أو نافذة صلاحيات النظام.
- المنصة محلية، لكن أداة الوكيل قد ترسل النصوص والصور المستلمة إلى مزود النموذج وفق إعدادها. التسجيل المشفّر الأولي مختلف عن سجلات الوكلاء والمهام المحلية التي تكون ملفات نصية مع تنقيح جزئي للأسرار.
- لا يوجد قارئ مباشر لملفات أوفيس أو تجاوز للحماية في هذا الإصدار؛ يمكن التحكم في واجهتها المصرح بها. التكامل التفصيلي عبر واجهات أوفيس البرمجية مرحلة تالية.

## تجربة سريعة

فحص البيئة والأدوات المتاحة:

```powershell
python main.py doctor
python main.py tools
python main.py integrations
```

تشغيل مسجل العمل الأول:

```text
Start-Recorder.cmd
```

إيقاف المهام عند حد التحقق التالي، ثم استئناف السماح بالتنفيذ بعد مراجعة الشاشة:

```powershell
python main.py stop
python main.py resume
```

التوقف لا يعكس عملية حدثت بالفعل، ولا يضمن قطع استدعاء نظام معلّق فورًا.
