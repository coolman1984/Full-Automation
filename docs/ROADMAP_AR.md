# الفجوات والأولويات

الأولوية حسب أثرها على مهمة فعلية. يتغير وضع البند عند توثيق دليل نجاحه.

| الأولوية | القدرة أو الفجوة | المطلوب لإقفالها |
|---|---|---|
| أولى | إثبات التحكم والجدولة على ويندوز ١١ | تجربة المسجل وعناصر الواجهة والكتابة واللقطات على تطبيق اختبار، ثم مهمة مجدولة بحساب المستخدم. توثيق القفل والصلاحيات |
| أولى | التكامل المباشر مع أوفيس في بيئة الشركة | تجربة اتصال بمكوّن أوفيس الرسمي على جهاز معتمد باستخدام ملف اختبار محمي ومصرح به، ثم التحقق من القراءة أو الحفظ داخل التطبيق |
| أولى | تجربة الوكلاء الأربعة بحسابات قائمة | تثبيت الإصدارات المحلية، واختبار الربط واستدعاء أداة واحدة وقراءة نص واضح لكل عميل |
| تالية | مراقبة عرض كروم داخل الإطارات والاختصارات | ترجمة الضغط والكتابة داخل الإطارات والاختصارات والتمرير لخطوات قابلة للإعادة، وتجربة المراقبة بماوس وكيبورد حقيقيين على ويندوز |
| تالية | سهولة التحكم في صفحات بإطارات متعددة | إضافة استهداف الإطار للأوامر الشائعة وإثبات الضغط والكتابة على حالات متعددة المصادر |
| تالية | تحسين تسجيل العروض البشرية | قياس نسبة الخطوات القابلة لإعادة التشغيل عبر تطبيقات مختلفة، وتصنيف ما يحتاج مراجعة |
| تالية | إدارة دورة حياة السجلات | التقسيم وحذف الإيصالات القديمة موجودين. المتبقي: تصدير إيصالات التشغيل لملف قبل حذفها |
| لاحقة | استرجاع عمل توقف في منتصف الخطوات | نقاط استئناف موثقة للمراحل القابلة للإعادة فقط، بعد إثبات أن المخرجات لم تُكتب مرتين |
