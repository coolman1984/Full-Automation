# دليل التشغيل والاسترجاع

قبل أي مهمة، حدّد التطبيق والمدخلات والمخرجات المطلوبة. جرّب على نسخة أو صفحة اختبار. ابدأ من [خريطة المشروع](../PROJECT_MAP_AR.md) لتحديد الأداة المناسبة.

| الحالة | الإجراء |
|---|---|
| أداة الوكيل مش ظاهرة | شغّل فحص البيئة، راجع ملف الربط والأمر والمسار المطلق، ثم افتح جلسة جديدة من مجلد المشروع |
| كروم بيرفض الاتصال | راجع المنفذ والملف المخصص. اختبر قائمة التبويبات. لو المتصفح قائم على منفذ مختلف، اتصل به صراحة واحفظه في تعريف المهمة |
| محدد الصفحة رجّع أكثر من عنصر | خُد معاينة جديدة وحدّد عنصر واحد. في الإطارات المعزولة حدّد الجلسة الصحيحة قبل أمر المتصفح المباشر |
| نافذة ويندوز غير متاحة | افتح جلسة المستخدم، ارفع القفل، واختر نافذة واحدة معروفة. افحص حالة الشاشة وصلاحية التطبيق |
| الفحص كشف خطوة يدوية | راجع التسجيل وبدّلها بخطوة واضحة يمكن التحقق منها. افحص كل الفروع قبل الجدولة |
| المهمة فشلت أو اتأخرت | راجع آخر محاولة وخطوتها. افحص التطبيق والناتج؛ ممكن الأمر يكون أحدث أثر قبل ظهور الخطأ |
| الملف الناتج موجود من قبل | سجّل وقت تعديله قبل التنفيذ. اشترط وقتًا أحدث، ثم افحص الحجم والبصمة لو المهمة تحتاج إثبات تغير المحتوى |
| تحتاج إيقاف محاولة واحدة | اطلب إلغاء المهمة من نفس اتصال الوكيل وتابع لحد الحالة النهائية. افحص أثر الخطوة الجارية |
| تحتاج إيقاف عام | شغّل أمر الإيقاف. استأنف بعد مراجعة الحالة، لأن الإشارة تستمر على القرص |
| شاشة أو نص حساس | اختَر أضيق نافذة ومدخلات لازمة. اقرأ قواعد جهة العمل قبل إرسال لقطات أو نصوص لنموذج خارجي |

```powershell
python main.py doctor
python main.py stop
python main.py resume
python main.py call workflow_history
```

## الجدولة

١. احفظ تعريف المهمة وافحصه بمدخلات ممثلة. جرّبها وتأكد من الناتج قبل تحديد المواعيد.
٢. اعرض تعريف الجدولة وتأكد من اسم المهمة، المواعيد بتوقيت ويندوز، والمستخدم الذي يشغّلها. سجّل الموعد المطلوب.
٣. اختبر تسجيلًا تجريبيًا على ويندوز. راجع نتيجة المجدول وسجل محاولة المهمة. مهام سطح المكتب تعتمد على جلسة تفاعلية مفتوحة وغير مقفلة.
٤. تغيير الوصفة يغيّر بصمتها. بعد المراجعة حدّث تسجيل المهمة. إن بقيت محاولة قديمة بحالة تشغيل بعد إغلاق العملية، راجع المخرجات قبل إعادة التنفيذ.
