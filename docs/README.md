تُكتشف مهارات المشروع من مجلد كلود أو كودكس داخل المستودع. ابدأ جلسة الوكيل من مجلد المشروع. كلود يشغّل المهارة باسمها بعد الشرطة المائلة، وكودكس يختارها من مهارات المشروع أو يستدعيها بالاسم بعد علامة الدولار.

## دورة التحديث

١. عدّل تعريف الأداة في الكود ووثّق أثر التغيير للمستخدم في سجل الإصدار.
٢. عدّل الخريطة أو دليل الاسترجاع إذا تغير مكان القدرة أو طريقة تشغيلها.
٣. سجّل القرار الدائم وسببه، أو الدرس المثبت ومعه الاختبار. اربط المعلومات بدل نسخها في صفحات متعددة.
٤. عدّل مهارة كلود الأصلية ثم ولّد الفهرس ونسخة كودكس وافحص الروابط.

```powershell
python scripts/docs_check.py
python scripts/docs_check.py --check
```

مرجع الأداة هو تعريفها في المحرك. مرجع إجراءات المهارة هو ملفها الأصلي في مجلد كلود. سجل القرارات والدروس يحتفظ بالدليل، وصفحة التحقق تفرّق بين ما بُني وما شُغّل فعليًا.
