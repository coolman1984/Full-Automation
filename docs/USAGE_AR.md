# التشغيل على ويندوز ١١

فك المشروع في مكان ثابت، وشغّل ملف الإعداد ثم ملف ربط كلود. افتح جلسة كلود جديدة وتأكد إن أدوات المنصة ظهرت.

```text
Setup.cmd
Connect-Claude.cmd
```

```powershell
claude --model claude-opus-5-5
```

## تعليم مهمة

١. ابدأ بتحديد النتيجة المطلوبة، زي ملف في مسار محدد أو قيمة على الشاشة.
٢. افتح كروم بملف تشغيل مخصص، أو حدّد نافذة ويندوز. اعمل تسجيل الدخول بنفسك لو مطلوب.
٣. خلّي الوكيل يبدأ تسجيل أدواته، ينفذ المهمة، ويفحص النتيجة.
٤. بعد الحفظ راجع المتغيرات، زي تاريخ التقرير واسم الملف. أعد التجربة بقيم مختلفة.
٥. صدّر كود المهمة أو شغّلها بالمواعيد التي تختارها. المواعيد حسب توقيت ويندوز. مهام سطح المكتب تحتاج جلسة مفتوحة وغير مقفلة.

لتجربة التحويل من عرض بشري، افتح المسجل الأصلي، واختر البرنامج، وسجّل مهمة قصيرة ثم احفظها. أعطِ الوكيل مسار الجلسة واطلب استيرادها وإكمال الخطوات اليدوية. سجلات الجلسة تُفك بحساب ويندوز الذي أنشأها.

## تجربة المتصفح على صفحة محلية

شغّل خادم المثال المحلي في نافذة أوامر مستقلة:

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory examples
```

افتح كروم بملف تشغيل مخصص على المنفذ الافتراضي، ثم احفظ المهمة وشغّلها:

```powershell
python main.py call browser_launch
python main.py workflow save examples/browser-form.json
python main.py workflow plan browser-form --variables-file examples/browser-inputs.json
python main.py workflow run browser-form --variables-file examples/browser-inputs.json
python main.py workflow export browser-form
```

يتحقق المثال من ظهور النص الذي كتبته. ملف المدخلات يحتوي بيانات مصطنعة فقط. الجدولة تحتاج أن يظل كروم متاحًا عند التشغيل أو أن تبدأه المهمة نفسها بطريقة مناسبة للبيئة.

## قراءة محادثة

لو المنصة بدأت جلسة الوكيل، تابع الأحداث باستخدام أدوات الجلسة ومعرّفها. لو عندك ملف محادثة قديم، أعطِ مساره صراحة. ولرؤية نافذة طرفية مفتوحة، حدّدها من قائمة نوافذ ويندوز، ثم اطلب قراءة عناصرها أو لقطة حديثة.

## الفحص والإيقاف

```powershell
python main.py doctor
python main.py stop
python main.py resume
```

التوقف يُفحص بين الخطوات ولا يلغي ما تنفذ. لو ظهر فشل أو مهلة، راجع حالة البرنامج قبل إعادة المحاولة. لو تم تعديل المهمة بعد جدولتها، راجع التعديل وحدّث تسجيل المهمة في المجدول.

راجع [دليل الاسترجاع](operations/RUNBOOK_AR.md) لمعرفة طريقة إلغاء محاولة واحدة، وقراءة سجل الخطوات، والتحقق من حداثة المخرجات.

أدوات التحكم تعرض النصوص والصور للوكيل الطالب. اتبع سياسة جهة العمل عند استخدام نموذج سحابي مع بيانات داخلية.
